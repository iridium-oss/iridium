# Synthetic Data

All files in this directory are synthetic or illustrative. They are used for local development, tests, and demos. No real city or user data is included. Schema and semantics align with docs/data-sources.md and packages/schemas.

Files:
- sensor_events.json: road sensor observations
- gnss_points.json: aggregated GNSS-derived points (no device identity)
- weather.json: meteorological snapshots
- public_events.json: public event calendar
- energy_signals.json: optional grid signals
- district_scores.json: district-level baseline for equity module
