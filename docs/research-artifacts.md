# Research Artifacts

This document lists research-related artifacts in the IRIDIUM repository and how they are versioned and cited.

## In-Repository Artifacts

| Artifact | Location | Description |
|----------|----------|-------------|
| Problem statement | research/problem-statement.md | Motivation and scope. |
| Methodology | research/methodology.md | Approach and methods. |
| Evaluation plan | research/evaluation-plan.md | Metrics and evaluation design. |
| Risks and limitations | research/risks-and-limitations.md | Known limitations and bias risks. |
| Literature review | research/literature-review.md | Related work (if present). |

## Versioning and Citation

- These documents are versioned with the software. To cite a specific state, cite the repository release (or Zenodo DOI) that contains that state.
- No separate DOI is assigned to individual documents unless published elsewhere (e.g. as a preprint or paper). For a preprint or paper that describes IRIDIUM, see docs/preprint-readiness.md and docs/preprint-checklist.md.

## Reproducibility

- Experiments or results that depend on the codebase should reference the exact commit or release (e.g. tag or Zenodo DOI) and the environment (Python/Node versions, optional dependencies) used. See docs/software-archiving.md.
